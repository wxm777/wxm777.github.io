我是谁

一名在校学生，ID：smile cat，方向是网络安全（渗透测试 / 漏洞挖掘）。

这个博客是我的技术自留地：一个漏洞完整的思考链、一个工具从痛点到实现的过程，都放在这里。

技能栈

AI 驱动的漏洞挖掘工作流（自主设计并持续迭代）

  • 设计了一套”AI × 渗透”的分层攻击工作流：S1 低成本探测收集信号 → S2 构建世界模型与假设树 → S3 模拟人工精确验证 → A1/A2 学习与记忆闭环，让 AI Agent 按人工渗透的节奏和方法论挖洞，而不是无脑跑 payload
  • 基于 Claude Code 实现并持续迭代，沉淀了完整的工程约束：合规红线体系、价值过滤、证据链归档规范、任务快照与断点续测
  • MCP 工具链编排：将浏览器（Playwright MCP）、Burp Suite 深度接入 AI Agent，浏览器侦察与精确发包按场景自动分工，WAF 场景自动降速切换

渗透知识工程化

  • 三层知识库设计：秒杀卡（30 秒快查）/ 决策树（验证路径）/ 深度技法（绕过手册），每次实战后结构化沉淀，随实战自然生长而非教科书搬运
  • “骨架库”机制：把同类系统的指纹、数据模型、鉴权模式、开发者犯错模式抽象成可复用模板，新目标秒级匹配历史攻击链

自动化工具链封装

  • 被动资产收集流水线：子域名 / DNS 解析 / IP 归属与 ASN 富化全流程并行编排，强调低噪声、边界控制与降级容错（任一数据源失效不卡死整体流程）
  • Python 安全工具开发：高并发扫描器、离线破解工具的设计与实现（见 HawkEye-Scanner 一文）

漏洞挖掘实战

  • 教育 SRC 授权测试：SQL 注入、未授权访问、文件上传、批量敏感信息泄露等高危漏洞的完整挖掘与报告经验
  • 本博客的复盘文章均来自真实授权测试（目标已脱敏），每个漏洞都有从信号到实锤/证伪的完整判断链

这个博客写什么

不写入门教程，不写复制粘贴的复现笔记。这里只记录真实的思考过程：

  • 漏洞复盘：一个漏洞从信号到实锤（或证伪）的完整判断链，重点讲”为什么这么测”，而不是”点了哪里”
  • 工具开发笔记：造轮子过程中踩过的坑，以及为什么现有工具解决不了我的问题
  • 方法论总结：挖洞的节奏、红线的把握、报告怎么写才站得住

我相信的是：复现一个漏洞只能学会这个漏洞，复现一条思路才能学会挖洞。
